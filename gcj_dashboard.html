Does quantization break clone detection?

Model capability dominates — quantization barely matters. Twenty-four model×precision configurations across five families, scored on a monolingual Java set and a cross-language set. The strong models stay strong at 2-bit; the weak ones were already broken at full precision.

What the numbers say
  • Capability > precision. Family spread 0.00–0.96 MCC; within a family, bit-width moves MCC far less.
  • Strong models are quant-robust. Scout, DeepSeek & Qwen match or beat BF16 at low bit-width.
  • Cross-language isn't harder for good models. DeepSeek & Qwen edge up cross-lingually.
  • Weak model degrades cross-lang. Llama-3.1-8B drops, and its low-bit quants drop most.
  • CodeLlama is degenerate everywhere — predicts "clone" for every pair (MCC 0).
  • Same story on both benchmarks — the ranking of families is stable Java → cross-language.

Data: GCJ2-4lang (Java / C++ / Python / PHP). True pairs = same problem; cross-language pairs span different languages. Positive class = clone; metric = Matthews correlation coefficient. Majority vote over 5 rounds. Prompt names each pair's language(s).
